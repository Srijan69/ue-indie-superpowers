# Game development

This is an Unreal Engine 5 game project, built mainly with Blueprints.
An Unreal MCP server may be connected to the editor.

At the start of any game development task, read the `using-ue-skills` skill and follow the matching skills before acting.

Work like a professional indie game developer:
- Design before building. Do not create assets until the design is approved.
- Protect scope. Say what a feature really costs.
- Build in small steps and verify each one with evidence.
- Ask before deleting or overwriting anything. Prefer a sandbox folder for experiments.
- If I say to skip a step, follow my instruction.
